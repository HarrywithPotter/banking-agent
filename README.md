# 智银 · AI Banking Agent

自然语言驱动的银行 AI 智能体：用户用大白话描述需求，系统自主理解意图、规划任务、在严格安全框架内完成银行业务。

## 快速启动

双击桌面 `Fintech\启动智银银行AI助手.bat`，浏览器自动打开 http://127.0.0.1:8000

或命令行：
```
pip install -r requirements.txt
python run.py
```

## 界面
- 中间：仿豆包/DeepSeek 暗色聊天窗口（输入栏 + 对话区）
- 右侧：修改日志 / 决策链路审计面板（实时刷新）
- 顶部：余额、锁定金额概览

## 安全机制
- **三级权限**：绿色自动 / 黄色确认 / 红色强验证（短信+人脸）
- **动态分级**：转账按当日累计，>1000自动升级红色（防拆单）
- **双沙箱**：代码沙箱（受限子进程）+ 数据沙箱（独立SQLite）
- **注入防御 + 熔断 + 全链路审计**

## 数据库
`data/banking.db`（SQLite），可用 DB Browser for SQLite 直接打开编辑，含客户/银行卡/流水/订阅/订单/资金锁定/定时转账/审计日志共8张表。右上角「重置演示数据」可恢复初始。

## 技术栈
Python 3.10+ · FastAPI · SQLite · 原生 HTML/JS 暗色UI · 无外部大模型依赖
